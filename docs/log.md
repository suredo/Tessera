# Documentation log

## 2026-10-17

* **Creation**: The [CLI contract spike](code/evals/cli-contract-spike.md) code doc ([issue 19](https://github.com/suredo/Tessera/issues/19), rehearsal): three planned calls that check Claude Code accepts a zod-generated schema (`CON-01`), keeps working with the locked flags (`CLI-03`) and returns structured output intact, rehearsed for free against a fake `claude` that records what it was given. The CLI starts from an allowlisted environment, since a parent Claude Code session sets variables such as `ANTHROPIC_BASE_URL` that removing API keys alone would let through (`CLI-08`). No live call has been made.

* **Creation**: The [evaluation harness](code/evals/harness.md) code doc ([issue 18](https://github.com/suredo/Tessera/issues/18), second part): any provider wrapped for an evaluation run with a hard call cap that never grows, a ledger line for every call and a request log line for every call that started, the run's own new or empty data folder (`ENG-19`), a stop after provider errors (`ENG-07`), and a dry run that refuses any provider able to reach a model (`OBS-02`). The [contracts package](code/contracts/package.md) gains the ledger and request log entries, with their JSON Schema (`OBS-01`).

* **Creation**: The [provider adapters](code/server/providers.md) code doc ([issue 18](https://github.com/suredo/Tessera/issues/18), first part): the one interface every model connection implements (`CLI-01`), and a scripted provider that answers from canned replies chosen by test configuration, never by the request's words (`ENG-11`, L-09). Replies come in order, each for a named stage; the host checks each answer against the stage's schema; a scripted call costs nothing. The [contracts package](code/contracts/package.md) gains the provider shapes: stages, efforts, error kinds (`CLI-05`), usage where unknown is null and never 0 (`CLI-04`), and the script format.
