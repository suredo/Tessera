# Code

* [CI](ci/index.md) - The CI workflow on GitHub Actions: what runs on every pull request and on main, and where.
* [Contracts](contracts/index.md) - The @tessera/contracts package: shared shapes, their JSON Schema and the unit rule.
* [Evals](evals/index.md) - The @tessera/evals package: so far, the evaluation harness with its budget guard, call ledger and dry run.
* [Scripts](scripts/index.md) - The repository's own tools: the OKF check, the git hooks, and the requirement and lesson coverage report.
* [Server](server/index.md) - The @tessera/server package: so far, the local server on 127.0.0.1 with its request guard, the platform helpers for paths and starting programs, the provider interface with its scripted provider, and SQLite storage with migrations.
* [Web](web/index.md) - The @tessera/web package: the host app, React with the React Compiler, and the translation layer.
