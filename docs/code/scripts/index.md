# Scripts

* [Coverage report](coverage-report.md) - Every requirement and lesson with its milestone, proposed, implemented or verified status, evidence and remaining limits, read from the docs and the tests; run in CI.
* [Git hooks](git-hooks.md) - Local git hooks, turned on by pnpm install: pre-commit refuses likely secrets, videos and images over 1 MB; pre-push refuses pushes to main.
* [OKF check](okf-check.md) - Checks the docs bundle, code docs, task handoffs, skills and the rules files, and fails the build when one breaks a rule; --fix repairs index entries and generated symbol sections.
