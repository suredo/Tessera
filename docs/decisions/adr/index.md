# Decisions from M0 on

* [ADR 0001. Suggesting a checkpoint](0001-checkpoint-suggestions.md) - An assistant may suggest a checkpoint in one line, saying why; it never runs one unasked (decides D12).
* [ADR 0002. The Claude Code CLI contract](0002-claude-code-cli-contract.md) - What the M0 CLI spike found on Claude Code 2.1.296, and the rules it sets for passing schemas, flags, environment and sign-in to the CLI.
* [ADR 0003. The SQLite access layer](0003-sqlite-access-layer.md) - Tessera reaches its SQLite database through Node's built-in node:sqlite, with plain SQL, rows checked by the zod contracts, and numbered migration files.
* [ADR 0004. Nested frames in the sandbox](0004-nested-frames-in-the-sandbox.md) - Frames a tool nests inside its own: those from URLs, data:, blob:, objects and embeds don't load; srcdoc and javascript: frames may run, and must be exactly as confined as the tool (changes SBX-06).
* [ADR 0005. A public repository](0005-public-repository.md) - Tessera's repository is public from 2026-10-21, so CI's Actions minutes are free; replaces A16, and what it changes for CI, branch protection and the owner's details in the history.
* [ADR 0006. DNS lookups from blocked frame navigations](0006-dns-lookups-from-blocked-frame-navigations.md) - A blocked frame navigation in the sandbox still makes Chrome and Edge resolve and connect to its address: accepted as a known limit of CSP for M1, with a partial runtime block to reconsider at the start of M2.
* [ADR 0007. Asset references found by scanning](0007-asset-references-by-scanning.md) - The asset store finds what still refers to an asset by looking through everything stored when it cleans up, rather than keeping reference rows that every write path must update; it changes DATA-11's wording.
* [ADR 0008. Splitting a request: mixed against data, and the request's own words](0008-intent-split.md) - How the intent stage tells a mixed request from a data change (by the records the open tool already keeps), and how the host keeps each split part in the request's own words: the whole request where nothing is split, a word check where it is, one more ask, then the person.
* [ADR 0009. Frames and navigation in generated tools](0009-frames-and-navigation-in-generated-tools.md) - Before generated tools run, ADR 0006's open limit is decided again: a tool steered by pasted data could leak a person's data through the names a blocked frame navigation makes the browser look up. The static check refuses frames, navigation, property names built at run time and code made at run time before any candidate or imported tool runs.
