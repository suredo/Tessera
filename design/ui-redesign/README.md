# UI redesign mockups

Static, self-contained HTML mockups of the proposed host app redesign, from Codex's third design round on 2026-11-20. The proposal and its decisions are in `docs/roadmap/ui-redesign.md`. Open `overview.html` first. Render any of them to PNG with `node design/ui-redesign/render.mjs design/ui-redesign <out folder> '[["a-focus.html",1440,900]]'` (desktop files are 1440x900, phone files 390x844, the overview 1600x1000).
